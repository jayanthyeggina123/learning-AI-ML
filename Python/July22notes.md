# Python Notes - Definitions

# Functions

**Definition:**  
A function is a block of reusable code that performs a specific task. It helps avoid writing the same code multiple times.

---

# Return

**Definition:**  
The `return` statement sends a value back from a function to the place where it was called.

---

# add_num()

**Definition:**  
`add_num()` is a user-defined function used to add two numbers and return the result.

---

# is_prime()

**Definition:**  
`is_prime()` is a function that checks whether a number is prime or not. It returns `True` if the number is prime; otherwise, it returns `False`.

---

# Iterators

**Definition:**  
An iterator is an object that returns one value at a time. It stores the current position and is used internally by the `for` loop.

---

# iter()

**Definition:**  
`iter()` converts an iterable (such as a list, tuple, or string) into an iterator.

---

# next()

**Definition:**  
`next()` returns the next value from an iterator. If there are no more values, it raises a `StopIteration` error.

---

# Generators

**Definition:**  
A generator is a special function that generates values one at a time using the `yield` keyword. It saves memory because values are created only when needed.

---

# yield

**Definition:**  
`yield` returns one value at a time and pauses the function. The function continues from the same point when called again.

---

# genCubes(n)

**Definition:**  
`genCubes(n)` is a generator function that generates the cube of numbers from `1` to `n` one at a time.

---

# genFibon()

**Definition:**  
`genFibon()` is a generator function that generates Fibonacci numbers one at a time using `yield`.

---

# map()

**Definition:**  
`map()` applies a function to every element in an iterable and returns the mapped values.

---

# reduce()

**Definition:**  
`reduce()` takes multiple input values and reduces them to a single output value by repeatedly applying a function.

---

# Lambda Function

**Definition:**  
A lambda function is a small anonymous function written in a single line using the `lambda` keyword.

---

# filter()

**Definition:**  
`filter()` returns only the elements that satisfy a given condition (True values) from an iterable.
